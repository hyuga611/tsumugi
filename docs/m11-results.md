# M11: 今どきの端末に足りていなかったもの

「SNS 用の紹介動画を撮りたいので、全部ちゃんと動くか見てほしい。あと、
今どきの端末にするうえで要る機能は？」という問いから始まった 8 つ。

## 1. 検索（`/` `?` `n` `N`）

端末の基本機能で、無いのが一番大きい欠落だった。

- **打つたびに飛ぶ。** 一覧を眺めてから決める手間を入れない。
- **Esc で探し始めた場所へ戻す。** 見つからないまま迷子にしない。
- 一致は選択とは**別の色**で光らせる。同じだと、選んだのか見つかったのかが
  区別できない。
- 端まで行ったら反対の端へ回る。端で止まると「無い」のか「そこまで」なのかが
  分からない。
- **桁で答える。** 全角が混じると文字数と桁数はずれる。ここを混ぜると、
  見つけた場所へ飛んだときにカーソルが 1 桁ずれる（テストで押さえた）。

## 2. ラベル（`Space l`）

画面のパス・URL に `a s d f …` を振って 1〜2 キーで開く。

**在るものだけに振る。** `open_kind`（Ctrl＋クリック用）は下線が騒がしく
ならないよう控えめに作ってあり、拡張子か区切りを要求する。ラベルでそれを
使うと、`crates` や `docs` のような**拡張子の無いフォルダに振られず**、
代わりに `10.0.26200.9168]` のような版番号に振られた。開けるかどうかは
聞けば分かるので、**実際に在るかどうか**で決める。

**行頭から始まるものは左のふちに置く。** 1 文字目に重ねると `.cargo` が
`acargo` に見えて、何のラベルか分からない（実機で読めなかった）。

フォルダを選んだらプロンプトへ `cd` を置く。「開ける形ではありません」で
終わらせない。

## 3. 畳み（`Space o` / `Space O` / `Space U`）

AI の出力は長い。畳めないと、前のやり取りへ戻るだけで一苦労になる。

- 境目は**シェル統合（OSC 133）**が教える。空行で当てにいくと出力の途中で
  切れる。diff は `diff --git` の間。
- **見せる側と当てる側で同じ関数**（`PaneView::line_at`）を通す。別々に
  数えると、クリックした行と実際に触る行が畳んだ分だけずれる。
- 要約に**何を畳んだか**を出す。diff ならファイル名、端末ならコマンド。
  行数だけだと、5 つ並んだときにどれがどれか分からなかった。
- 検索が畳んだ中に当たったら開く。件数だけ数えて行けない場所を作らない。

## 4. 同報と突き合わせ（`Space b` / `--broadcast` / `--compare`）

同じ問いを複数のエージェントへ同時に投げ、返事が揃ったら並べて見比べる。
`--layout agents` は 3 分割で開く。

投げた先は全部「動いている」にしておく。**投げる前から返事待ちだった
ペインを見て「もう返ってきた」と誤らないため。**

## 5. `git diff` を色付きで（`Space g`）

`--color=never` で取って自前で色を付ける。相手の色コードを解釈し直すより、
**行の頭 1 文字を見るほうが確か**。ペインに開くので `n` で探せて
`Space o` でファイル単位に畳める。

## 6. コストの表示

`tsg --agent-state done --cost "$0.42"` で名乗らせ、そのまま出す。
**こちらでは数えない。** 数え方はモデルごとに違い、当てにいくと必ずずれる。

## 7. 画像（Kitty graphics protocol）

`timg -p kitty` / `chafa -f kitty` / matplotlib の kitty backend が出る。

- **`vte` は APC を捨てる。** 取り出す口が無いので、解析器へ渡す前に
  バイト列から抜き出して、残りだけを流す。
- **PTY は都合のよい位置で切れてこない。** またいでも同じ結果になることを
  テストで押さえた（切る位置を 1 バイトずつ変えて全部試す）。
- 絵は**ドキュメント絶対行**に置く。スクロールバックと一緒に動き、
  履歴から落ちたら消える（印と同じ扱い）。
- 描画はシェーダに `mode 2` を足しただけ。既存の字と矩形の道は触っていない。
- Sixel はまだ無い。

## 8. 外から画面を動かす（`--run` / `--search` / `--commands`）

窓の中でしか起きないこと（検索・ラベル・畳み・配色）を台本から動かす口。
**これで画面の確認が合成キー無しで回るようになった** — 人がキーボードを
使っている最中でも、機能の確認ができる。副産物ではなく、いちばん効いた。

## 実機で見て出たもの

画面を見ないと分からないものばかりだった。

| 出たこと | 直し方 |
|---|---|
| ラベルが出しっぱなしで本文の 1 文字目を隠していた | 別のコマンドを始めたら消す |
| ラベルが版番号に付き、フォルダには付かない | 在るものだけに振る |
| ラベルで `.cargo` が `acargo` に見える | 行頭のものは左のふちへ |
| フォルダのラベルが「開けません」で終わる | プロンプトへ `cd` を置く |
| 畳んだ diff が 5 つとも同じ見た目 | 要約にファイル名を出す |
| 検索が畳んだ中に当たると行けない | 当たったら開く |
| README の引用で `**` が字のまま出る | 強調の開閉を段落の中で持ち回す |
| コードブロックの長い行が窓からはみ出す | 折り返す（**詰め直さない**） |

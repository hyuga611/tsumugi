# M9: 行き止まりを塞ぐ

実機で使った人（作者以外）が最初の 5 分で踏んだ 3 つを直した。
どれもテストは全部通っていて、**画面を見ないと分からない**類だった。

## 1. 一覧が下へ伸びず、選択が画面の外へ消える

パレットは頭から 14 件を切り取って出すだけだった。`↓` で 15 件目へ動くと
選択の帯が消え、Enter が何を実行するのか分からなくなる。53 件のうち
39 件は**存在しないのと同じ**だった。「端末へ戻る」もその中にあった。

同じ形の欠陥が 4 か所にあった。

| 場所 | 起きていたこと |
|---|---|
| コマンドパレット | 15 件目から下が見えない |
| セッション一覧 | 15 個目から下が見えない |
| 右クリックメニュー | 29 行あるので、低いウィンドウで下が画面外へ出る |
| 使い方（F1） | 入り切らない行が黙って消える。**閉じ方の 1 行が最初に消えた** |

`overlay::scroll_into_view` を 1 つ置き、一覧は全部そこを通す。
上下に隠れていれば `▲` `▼` を出し、パレットは `17 / 53 件` と現在地を出す。
ホイールも一覧に効くようにした（**開いている一覧ではなく後ろの本文が動いていた**）。
使い方は `↑↓` で送れるようにし、閉じ方の 1 行は最下行に固定した。

回帰テスト: `the_palette_keeps_the_selection_inside_the_window` /
`every_menu_item_is_reachable_in_a_short_window` ほか 5 本。
「見えている行」と「クリックで動く行」が食い違わないことも押さえた。

## 2. ファイルを開くと帰り道が見えない

`:q` と右クリックメニューの「端末へ戻る」はあったが、
ステータス行の `≡ メニュー` が開くのは**パレット**で、そこでは 1 の欠陥により
「端末へ戻る」が見えていなかった。キーを知らない人には行き止まりだった。

ファイルを開いているあいだだけ、ステータス行に `✕ 端末へ戻る` を出す。
1 クリックで戻る。使い方にも「ファイルを開いたら」の節を足した。

## 3. 設定ファイルを開くと真っ白

まだファイルが無いときに空で開いていた。何が書けるのか分からないうえ、
そのまま保存すると空のファイルができる。

`config::template()` を置き、無ければ雛形を書いてから開く。
既定値がそのままコメントで並ぶので、`#` を外すだけで効く。
`the_template_reads_back_as_the_default` が「雛形を置くだけで設定が変わらない」
「雛形が警告を出さない」を押さえる。

## 4. 使い方が毎回出る

起動のたびに全画面で出ていた（M5 の TODO が残っていた）。
一度読んだ人には邪魔なだけなので、**初回だけ**にする。
目印は設定と同じところ（`%APPDATA%	sumugi\welcomed`）に置く。
実行時の一時領域だと再起動のたびに「初回」へ戻る。
置き場所が分からない環境では今までどおり毎回出す（出ないより出すぎるほうがまし）。
2 度目からは `F1` と下の `? 使い方` から。

## 5. TUI が軒並み崩れる（Ambiguous 幅）

Claude Code を tsumugi の中で動かすと、枠線が `- - - -` の破線になり、
消したはずのプロンプト（`C:\Users\atlan>`）が新しい描画の上に残っていた。

原因は East Asian **Ambiguous** 幅。`─` `│` `╭` `█` `●` `•` `·` `←` は
どれも Ambiguous で、`width_cjk()` は 2 を返す。tsumugi は全部の桁勘定を
`AmbiguousWidth::Wide` で固定していたので、TUI が 1 幅のつもりで書いた字を
2 桁で置いていた。**枠が飛び飛びになり、消去とカーソル移動の桁もずれる**ので、
古い文字が消えずに残る。かな・漢字は Wide クラスなので無関係。

`arch.md` §6.1 は最初から `ambiguous_width = 1 | 2` を設計に入れていたが、
配線されていなかった（どこも `Wide` 決め打ち）。配線して**既定を 1 幅に変えた**。
設計時の既定（2・日本語端末の慣習）とは逆になる。TUI が崩れるほうが害が大きい。

プロセス全体で 1 つと決める（`tsg_term::set_ambiguous`）。ペインごとに違うと、
同じ文字列がペインをまたいだ瞬間に幅を変え、桁の勘定がどこかで必ず食い違う。
2 幅が要るなら `[font] ambiguous_width = "wide"`。読み直しでは変えない（言語と同じ）。

## 実機で確かめたこと

1100x730 / 1240x800 / 900x600 / 760x560 の 4 つの大きさで見た。

- パレットで `↓` を 16 回 → 選択が見えたまま、`17 / 53 件` と `▲` `▼` が出る
- 低いウィンドウ（560px）の右クリックメニュー → 下端に `▼`、ホイールで送れる
- 設定ファイルを開く → 雛形が構文強調つきで出る
- `✕ 端末へ戻る` を 1 クリック → シェルへ戻り、ボタンが消える
- F1 → `PageDown` で最後まで読める。閉じ方は常に最下行にある
- クライアントだけ落として開き直す → 設定ファイルを開いたまま復元される
- デスクトップのショートカットから 1 回目 → 使い方が出る。2 回目 → 出ない
- `claude` を中で動かす → 枠線が実線に戻り、消えずに残っていた前のプロンプトも消えた
